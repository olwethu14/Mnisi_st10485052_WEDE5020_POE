Blueprint Resumes website

Project Overview

Blueprint Resumes is a professional CV and career-document website designed for students, graduates, job seekers, and professionals.

The website provides users with information about Blueprint Resumes, the services offered, pricing, client testimonials, frequently asked questions, and contact information.

The main goal of the website is to provide a simple, professional, and user-friendly online platform where potential clients can learn about the services and request professional CV-related assistance.


Website Pages

The website has seven main pages:

1. Home

The Home page introduces Blueprint Resumes and provides an overview of the business.

It includes:

* navigation bar
* Hero banner 
* Introduction to Blueprint Resumes
* Call-to-action button for requesting a quote
* Services overview
* A footer

2. About Us

The About Us page provides information about Blueprint Resumes and its purpose.

It includes:

* About section
* Hero section
* Supporting image
* Mission, Vision and Promise

3. Services

The Services page explains the services provided by Blueprint Resumes.

The main services are:

* Professional CV
* CV Editing
* Cover Letter
The services are presented using service cards to make the information easy to understand.

4. Pricing

The Pricing page provides information about the costs of the available services.

The pricing information is presented in a structured table to make it easy for users to compare the different services.

5. Testimonials

The Testimonials page displays feedback from clients who have used the services.

This page helps visitors understand the type of experience clients can expect.

6. FAQ

The FAQ page provides answers to common questions about Blueprint Resumes and its services.

The page helps users find important information without having to contact the business directly.

7. Contact

The Contact Us page provides users with contact details and a way to compose a message.

It includes:

* A message area with Email Address, Phone Number, Subject, and Message labels
* A Send Message button
* Contact details, including phone number, email address, location, and business hours
* An Instagram icon
* Navigation links and footer quick links to the other website pages

Responsive Design

The website has been designed to work across different screen sizes.

CSS media queries are used to adjust the layout for smaller screens.


* Navigation changes layout on smaller screens.
* Service cards adjust their size and positioning.
* Content remains within the screen instead of overflowing.
* Images resize according to the available screen space.
* Tables are adjusted to fit smaller screens.

How to View the Website

To view the website locally:

1. Download or clone the repository.
2. Open the project in Visual Studio Code.
3. Open index.html.
4. Run the page using a web browser.
5. Use the navigation bar to access the other pages.
